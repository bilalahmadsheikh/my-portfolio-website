  • SSD-backed SQLite vault (50,000+ chats tested)
  • FTS5 full-text search with snippets and ranking
  • ZIP backups with point-in-time snapshots
  • Atomic writes: temp → fsync → rename
Privacy By Design

Open architecture.
Closed to the cloud.

Every component runs locally. From capture to storage, nothing leaves your machine.

6 Chrome Permissions Only

tabs, tabGroups, windows, storage, clipboardWrite, nativeMessaging. No broad host permissions. No webRequest.

Zero Outbound Requests

The vault makes no network calls. Your conversations never touch the internet.

No Cookie Capture

Technically impossible by design — missing permissions prevent any auth token or cookie access.

XSS Prevention Built-In

All user strings HTML-escaped. Content HTML is stripped before native messaging and disk write.

Scoped Content Scripts

Content scripts run only on the 6 supported AI platform origins — an explicit allowlist, nothing broader.

Source of Truth on Disk

The SSD vault is authoritative. Browser storage is only a write-through fallback cache.

Get Started

Three steps to permanence.

1

Add the Chrome Extension

Install gulaq from the Chrome Web Store and pin it. The side panel becomes your workspace manager and chat-capture hub.

2

Install the Desktop Vault

Run the desktop installer. It hosts your local SQLite vault on your SSD with full-text search, backups, and a timeline view.

3

Sign In & Start Saving

The extension links to your vault over a secure local connection — then save workspaces and capture AI chats, all stored locally.
